# دفتر حسابداری شخصی — نسخه ۳.۰ (دفترهای مستقل + دید دوجانبه)

اپلیکیشن فارسی RTL مدیریت بدهی/طلب شخصی، چندکاربری، با تقویم شمسی.

## تازه‌های نسخه ۳

- **دفترهای مستقل:** ثبت تراکنش دیگر نیازی به ثبت متقابلِ طرف مقابل ندارد (تطابق دوطرفه حذف شد).
- **شش نوع عملیات:** ثبت طلب اولیه، ثبت بدهی اولیه (موجودی آغازین)، ثبت طلب، ثبت بدهی، پرداخت به، دریافت از.
- **وضعیت تراکنش‌های من در حساب دیگران:** هر کاربر می‌بیند دیگران برایش چه ثبت کرده‌اند و روی هر ردیف می‌تواند کامنت بگذارد / کامنت‌های طرف مقابل را ببیند.
- **دسته‌بندی شخصی:** هر کاربر در «تنظیمات من» دسته‌های خودش را می‌سازد و به تراکنش می‌چسباند؛ داشبورد جمع‌بندی دسته‌ها را نشان می‌دهد.
- **طرف‌حساب مشترک/شخصی:** ادمین طرف‌حساب‌های مشترک را می‌سازد (با یا بدون پنل کاربری) و «دسترسی» هر کاربر را به آن‌ها تعیین می‌کند؛ هر کاربر همچنین طرف‌حساب شخصی خودش را می‌سازد (فقط دفتر خودش).
- **کنترل کامل ادمین:** فعال/غیرفعال‌سازی کاربران (ورود و ربات تلگرامشان مسدود می‌شود)، مدیریت کاربران/طرف‌حساب‌ها/دسترسی‌ها + گزارش‌های ممیزی.
- **ربات تلگرام v3:** مانده بر پایه شش نوع عملیات + نمایش دسته + رد کاربران غیرفعال.

## راه‌اندازی (خلاصه)

1. `npm install` → `npm run dev` (یا روی Vercel دیپلوی کنید)
2. Supabase SQL Editor: `supabase/schema-v2.sql` → `supabase/telegram-schema.sql` → `supabase/schema-v3.sql` (نصب موجود فقط v3)
3. کاربر اول را در Authentication بسازید (Auto Confirm) و با `select public.make_admin('UUID','vahid','وحید');` ادمین کنید
4. چهار Edge Function پوشه `supabase/functions/` را دیپلوی کنید (telegram-bot بدون Verify JWT)
5. Secret تلگرام `TELEGRAM_BOT_TOKEN` + setWebhook به `https://<ref>.supabase.co/functions/v1/telegram-bot`

جزئیات کامل در تب «راه‌اندازی» داخل خود اپ.
